# Индекс измерений

- `research-2026-10-28/`: окончательная основная серия, 96 UDP + 5 ON/OFF/burst + 12 TCP. Все сценарии complete, аудит 366/366.
- `socket-buffer-control-2026-10-28/`: дополнительный контроль буферов, 9 UDP. Complete, аудит 36/36.
- `unit-tests.log`: пять успешных unit-тестов.
- `smoke-04/`: успешная предварительная проверка CPU/UDP, native/sessions ON/OFF и TCP-PCAP до основной серии. Предшествует уточнению отсчёта reading time по ACK.
- `smoke-03/`: успешный ранний smoke без TCP-PCAP, до уточнения TCP-времён; не является итоговым результатом.
- `smoke-01/`: прерван после UDP — iPerf2 отверг сочетание `-b` и isochronous/IPG. Исправлено перед следующими пробами.
- `smoke-02/`: прерван на коротком capture sessions — без immediate-mode libpcap не выдал буфер до завершения захвата. Исправлено в последующих запусках; неполный capture не используется для выводов.
- `ipg-probe/`: парные измерения единиц IPG. По три основные пачки; early probe без immediate-mode, хвост capture неполон, медианный внутрипачечный IPG пригоден для различения единиц.
- `burst-probe-01/`: предварительная проверка принятия burst-опций, затем повторена с исправленным capture в основной серии.
- `tcp-duration-probe/`: исходные client/server JSON для проверки влияния `-i 1` и `-i 0.1`. Попытка `-i 0.01` была отвергнута инструментом; соответствующий эксперимент не состоялся.
- `probe-iperf*`: первые односекундные проверки наличия и работоспособности бинарников.

Промежуточные измерения не объединяются с основной матрицей. Графики предварительных проверок служат диагностике, итоговые графики находятся в двух окончательных наборах выше. Статусы, команды и неуспешные stdout/stderr сохраняются для аудита.
